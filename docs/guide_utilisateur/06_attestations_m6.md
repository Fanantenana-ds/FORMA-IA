# M6 — Attestations de formation

## Dans l'écran de session

1. Ajoutez toutes les séances de la formation.
2. Pour chaque participant et chaque séance, enregistrez **Présent**, **Absent**, **Retard** ou **Excusé**.
3. Ouvrez la carte **Attestations de formation · M6**, puis cliquez **Vérifier l'éligibilité**.
4. Vérifiez le taux affiché et l'état des pointages. Le seuil est de **75 %** ; les pointages manquants doivent être complétés avant de continuer.
5. Cliquez **Préparer les attestations**. Le lot est envoyé à la validation humaine.

## Vérifier et approuver les PDF

Dans **Espace IA → Validation IA**, ouvrez le lot d'attestations. Cliquez **Aperçu PDF** pour vérifier chaque page. Vous pouvez approuver une attestation à la fois, ou cliquer **Approuver toutes** après avoir contrôlé le lot.

Après approbation, le bouton **Télécharger** est disponible pour les attestations approuvées. Le bouton **Télécharger le ZIP** apparaît quand tout le lot est approuvé.

Les compétences présentées sont basées sur les supports RAG indexés, un syllabus déjà approuvé ou les thèmes des séances enregistrés. Si le contenu pédagogique ne permet pas de les établir, le système bloque la génération. La zone de signature du directeur doit être signée et tamponnée ; aucune signature manuscrite n'est ajoutée automatiquement.

## Si la génération est bloquée

- **Pointages à compléter** : revenez au tableau des présences et renseignez chaque séance pour chaque participant.
- **Aucun participant éligible** : seuls les participants ayant au moins 75 % de présence peuvent recevoir une attestation.
- **Lot déjà en attente ou déjà approuvé** : consultez Validation IA ou l'historique avant de demander un autre lot.
- **Contenu pédagogique insuffisant** : indexez les supports de la formation dans Base documentaire, approuvez le syllabus correspondant, ou renseignez les thèmes réels des séances.
