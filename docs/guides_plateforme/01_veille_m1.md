# Module M1 — Veille marché

## À quoi ça sert

Le module Veille marché surveille Internet pour détecter automatiquement des opportunités de formation : appels d'offres, demandes de formation, annonces. Il analyse le contenu trouvé avec l'intelligence artificielle et enregistre les résultats dans FORMA-IA avec un score de pertinence.

C'est l'outil idéal pour un directeur ou un chargé de développement qui veut rester informé des opportunités sans faire de recherches manuelles.

## Comment l'utiliser

**Mode 1 — Recherche manuelle :**
1. Ouvrez le module Veille marché dans FORMA-IA.
2. Saisissez des mots-clés décrivant le type de formation recherché (exemple : « formation en intelligence artificielle Madagascar »).
3. Lancez la recherche. Le système interroge le web et analyse les résultats automatiquement.
4. Si vous n'indiquez pas de zone géographique, Madagascar est ajouté par défaut.

**Mode 2 — Détection automatique :**
1. Lancez la détection automatique depuis le module.
2. Le système exécute un ensemble de requêtes prédéfinies correspondant au profil ALTIORA.
3. Une seule détection peut tourner à la fois. Si une détection est déjà en cours, attendez qu'elle se termine avant d'en lancer une nouvelle.
4. Vous pouvez vérifier l'état de la détection à tout moment.

**Analyser un document déjà en main :**
- Collez un texte directement dans le module pour une analyse immédiate.
- Ou téléversez un PDF (appel d'offre, cahier des charges) — taille maximale : 15 Mo.

## Ce qui se passe automatiquement

Les opportunités dont le score dépasse le seuil de pertinence sont automatiquement enregistrées dans FORMA-IA. Aucune validation manuelle n'est requise à ce stade.

## Si quelque chose ne fonctionne pas

- **Aucun résultat** : essayez une formulation plus générale, ou vérifiez que le sujet existe dans la zone géographique ciblée.
- **Détection refusée** : une détection est déjà en cours — patientez jusqu'à ce qu'elle se termine.
- **Erreur sur un PDF** : le document est peut-être un scan (image sans texte) ou un fichier corrompu — essayez avec un autre PDF.
