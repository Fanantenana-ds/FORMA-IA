# Module M2 — Termes de Référence

## À quoi ça sert

Le module Termes de Référence génère automatiquement un document TDR complet à partir d'un brief client : objectifs pédagogiques, public cible, durée, programme. C'est un gain de temps important pour les chargés d'offres et les directeurs qui préparent des propositions.

Si une opportunité a déjà été détectée par le module Veille marché (M1), les informations sont pré-remplies automatiquement — vous n'avez pas à ressaisir les données.

## Comment l'utiliser

1. **Pré-remplissage depuis une opportunité** : si vous partez d'une opportunité détectée, sélectionnez-la et les champs du formulaire sont remplis automatiquement.
2. **Remplissage manuel** : sinon, remplissez le formulaire avec le titre, le public cible, la durée, le domaine et les objectifs.
3. **Générer le TDR** : lancez la génération. L'IA crée un document structuré et professionnel.
4. **Télécharger** : une fois généré, le TDR est disponible en téléchargement immédiat (Word ou PDF).
5. **Consulter la liste** : accédez à la liste de tous les TDR générés depuis le module.

## Ce qui ne nécessite pas de validation

Le TDR est immédiatement disponible après génération — aucune approbation humaine n'est requise avant de le télécharger.

## Si quelque chose ne fonctionne pas

- **Erreur lors de la génération** : le service IA est peut-être temporairement indisponible — réessayez dans quelques minutes.
- **Téléchargement échoue** : vérifiez que vous sélectionnez le bon document dans la liste.
- **Liste d'opportunités vide** : aucune opportunité n'a encore été détectée par le module Veille marché — lancez d'abord une recherche dans M1.
