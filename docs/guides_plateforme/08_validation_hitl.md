# Validation humaine (HITL) — Guide pour les responsables

## À quoi ça sert

La validation humaine (HITL — Human In The Loop) est le processus par lequel un responsable vérifie et approuve chaque contenu généré par l'IA avant qu'il soit utilisé. C'est un principe fondamental de FORMA-IA : l'IA propose, l'humain décide.

Tous les modules qui produisent des contenus importants (offres, formulaires, analyses, attestations, rapports, relances) passent par ce processus de validation.

## Qui doit valider

Selon la criticité du contenu :
- **Critique** : approbation obligatoire avant toute utilisation (offres commerciales, attestations).
- **Important** : approbation recommandée (analyses de niveaux, satisfaction).
- **Standard** : approbation conseillée mais moins urgente (rapports internes).

## Comment valider une demande

1. **Accédez aux demandes en attente** : depuis le menu principal, ouvrez la section Validation ou Pending Reviews. Vous y voyez toutes les demandes d'approbation en attente.
2. **Consultez le détail** : cliquez sur une demande pour voir le contenu généré par l'IA, le module d'origine et la criticité.
3. **Approuvez** : si le contenu est correct, cliquez sur « Approuver ». Le processus continue automatiquement.
4. **Rejetez** : si le contenu n'est pas satisfaisant, cliquez sur « Rejeter » et indiquez le motif (minimum quelques mots). Le module d'origine pourra régénérer le contenu en tenant compte de votre retour.

## Consulter les statistiques

Depuis la section Validation, vous pouvez voir le nombre de demandes en attente, approuvées et rejetées pour chaque module.

## Si quelque chose ne fonctionne pas

- **La demande est introuvable** : elle a peut-être été supprimée ou le module n'a pas encore soumis de résultat — vérifiez que l'agent a bien terminé son travail.
- **Rejet refusé sans motif** : un motif est obligatoire pour rejeter — expliquez en quelques mots ce qui ne va pas.
- **L'approbation n'a pas d'effet** : vérifiez l'état de l'agent dans le module concerné (M3, M5, etc.) — le service IA est peut-être indisponible.
