# Base de connaissances — Assistant documentaire RAG

## À quoi ça sert

La base de connaissances est l'assistant documentaire intelligent de FORMA-IA. Elle vous permet de poser des questions en langage naturel sur les formations ALTIORA et d'obtenir des réponses précises extraites directement des supports pédagogiques indexés.

Exemples de ce que vous pouvez demander :
- « Quelles formations sont disponibles ? »
- « Quel est le contenu de la formation IA fondamentaux ? »
- « Où est expliqué le prompt engineering dans les supports ? »
- « Comment utiliser le module Veille marché ? »

## Comment l'utiliser

1. **Ouvrez le chat** depuis le menu principal de FORMA-IA.
2. **Posez votre question** en langage naturel — vous n'avez pas besoin d'utiliser des mots-clés techniques.
3. **Recevez la réponse** avec les sources citées. Si la réponse est basée sur un document, vous pouvez télécharger ce document.
4. **Continuez la conversation** : l'assistant mémorise le contexte de la conversation — vous pouvez poser des questions de suivi sans répéter les informations déjà données.

## Types de questions auxquelles l'assistant peut répondre

| Type | Exemple |
|------|---------|
| Catalogue | « Quelles formations proposez-vous ? » |
| Contenu d'une formation | « Que couvre la formation Python data ? » |
| Localisation d'un sujet | « Dans quel module est expliquée la notion de LLM ? » |
| Synthèse thématique | « Quelles formations traitent de l'IA ? » |
| Question de fond | « Quelle est la différence entre l'IA générative et l'IA classique ? » |
| Aide sur la plateforme | « Comment créer une formation dans FORMA-IA ? » |

## Important

L'assistant répond **uniquement** à partir des documents indexés dans la base de connaissances. Si un sujet n'est pas couvert par les documents disponibles, il vous le dira clairement — il n'invente pas de réponses.

Pour ajouter de nouveaux documents à la base, contactez l'équipe technique ALTIORA.

## Si quelque chose ne fonctionne pas

- **L'assistant répond « aucun support ne traite ce sujet »** : le document sur ce sujet n'est peut-être pas encore indexé — reformulez votre question avec d'autres mots ou contactez l'équipe.
- **La réponse est lente** : le service d'analyse des documents est parfois chargé — patientez quelques secondes.
- **Les suggestions de la plateforme** : utilisez-les pour explorer des sujets connexes sans avoir à formuler de nouvelles questions.
